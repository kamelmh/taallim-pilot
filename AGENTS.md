# AGENTS.md — Ta'allim Pilot (Education System)

## Cross-Project Protocol

### Before Starting Work
1. Read this project's `UPDATES.md` for recent changes
2. Check sibling projects' `UPDATES.md` for changes that might affect this project:
   - `../digital-services-center/UPDATES.md` — if working on PDF report generation
   - `../mahi-spiritual/UPDATES.md` — if working on Quranic content
   - `../../academix-dss/UPDATES.md` — if working on inventory/management features

### After Finishing Work
1. Append an entry to this project's `UPDATES.md`
2. Include: date, what changed, files affected, breaking changes, alerts for other projects

### Alert System
If your work produces something other projects should know about:
- **Arabic content** → Alert DSC project (also generates Arabic PDFs)
- **Font changes** → Alert DSC and KDP projects (PDF generation)
- **Assessment formats** → Alert any project consuming student data
